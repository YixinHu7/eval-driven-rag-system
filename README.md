# Evaluation-Driven RAG System

A production-oriented Retrieval-Augmented Generation (RAG) system for technical documentation, designed with evaluation, retrieval experimentation, and grounded answer generation in mind.

## Project Goal

This project aims to build a high-quality RAG pipeline over complex technical documents, with a strong focus on:

- retrieval quality
- citation-grounded answers
- evaluation-driven optimization
- experiment comparison across retrieval strategies
- production-oriented system design

## Planned Features

- Document ingestion and metadata extraction
- Dense retrieval baseline
- BM25 and hybrid retrieval
- Query routing
- Citation generation
- Confidence-based abstention
- RAG evaluation with automated experiments
- Failure analysis and observability

## Tech Stack

- Python
- FastAPI
- SQLite
- LanceDB
- BM25
- RAGAS
